# Keyboard Navigation

El POS es el único módulo con soporte de teclado deliberado y documentado: atajos visuales, edición de cantidad inline navegable sin mouse (commit `ec07751`). No se confirmó tab-order ni atajos de teclado auditados en el resto de los módulos — es terreno no cubierto, candidato a mejora si el objetivo de producto es que cajeros/encargados puedan operar toda la app sin mouse, no solo el flujo de cobro.
