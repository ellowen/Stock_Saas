# Empty States

`EmptyState.tsx` (`title`, `description`, `action?`) — usar siempre en vez de un `<p>` suelto cuando una lista/tabla no tiene resultados. No confirmado en esta ronda si todos los módulos lo usan de forma consistente en sus distintos estados vacíos (ej. "sin resultados de búsqueda" vs. "todavía no hay ningún registro" son mensajes distintos que EmptyState debería diferenciar) — auditar si se retoma este documento.
