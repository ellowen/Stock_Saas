# Design Principles

Ver `UX_GUIDELINES.md` (raíz) para el contenido completo — este archivo existe por la estructura de carpetas pedida y apunta ahí en vez de duplicar. Los 4 principios centrales, en una línea cada uno:

1. Velocidad y mínimos clics antes que estética.
2. Inline > panel in-place > modal, en ese orden de preferencia.
3. El código de barras es un teclado — todo buscador de producto debe aceptar `Barcode+ENTER` como flujo primario.
4. Un permiso ausente debería, idealmente, deshabilitar+explicar en vez de solo ocultar (patrón recomendado, no aún universal — ver `ux/permissions-ux.md`).

Validados en la práctica en el rediseño del POS (`modules/POS.md`), no aspiracionales.
