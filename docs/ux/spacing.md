# Spacing

No hay una escala de espaciado custom documentada — se usa la escala default de Tailwind (`p-1`...`p-12`, incrementos de 0.25rem). No se confirmó en esta ronda si existe una convención no escrita de qué padding usa cada tipo de contenedor (card, modal, tabla) más allá de lo que ya cubre `.card-minimal`/`.table-modern` en `index.css` (ver `DESIGN_SYSTEM.md`). Si se retoma este documento, el trabajo pendiente es auditar 3-4 pantallas representativas y extraer los valores de espaciado realmente repetidos, en vez de asumir una escala que no está escrita en ningún lado todavía.
